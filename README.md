# docencia_ia_udp
## Ecosistema Docente Inteligente (Act-IA + PassLink)

Repositorio de documentación, investigación estratégica y arquitectura técnica para la modernización de la docencia universitaria (UDP y multi-universidad).

### 📁 Contenido del Repositorio

- **[`investigacion_implementacion.md`](./investigacion_implementacion.md)**: Documento maestro de arquitectura técnica, hoja de ruta, integración con Canvas LMS, generador de Excel estándar del curso y estrategia multi-institucional SaaS.
- **[`contexto.md`](./contexto.md)**: Documento de postulación oficial al *Fondo Estudiantil Talento IA - UDP* para el proyecto **Act-IA** (agentes de IA para revisión y pautas en entregas iterativas).
- **[`OTRA_APP.md`](./OTRA_APP.md)**: Especificación funcional y modelo de seguridad anti-fraude para **PassLink / AsistLink** (sistema inteligente de control de asistencia presencial e híbrida).
